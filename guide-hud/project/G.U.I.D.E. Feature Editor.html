Authoring Guide
01Prose is enough

Fill in identity, write the description, save. Variables and Effects exist for features the app has to compute — they stay closed until you open them, and a feature that never opens them is a complete feature.

02when vs ask

Two different kinds of thing, deliberately drawn as two different rows.

whenA condition the app evaluates over variables and the sheet. False means the node contributes nothing and is never mentioned. hp < maxHp / 2 askA toggle a human flips at the table; the text is the label on it. Spend a use to press the attack? BothLegal and common: the app checks whether the choice is available, the player decides whether to spend it.
03Target selectors

A target list is a set of selectors, OR’d together. Empty means the node’s own roll.

ThingOne named entity from the catalog. Picked by name; the id is written on save. Tagtag:fire_damage — everything carrying the tag, following the catalog as it grows. Roll kindroll:save.dex, or roll:save for all of them. A class of roll, not a thing. Match countRead it every time. It is the only signal that separates a typo from a selector that correctly matches nothing yet.
04Variables
StoredWritten on the character and read back. Needs a type — Number or Boolean — and takes an optional initial value. DerivedNever stored. Recomputed from its formula on every read, so it has no type to pick. DM-onlyA permission, not a style. Amber means the player cannot write it — only this console can.
05Field types

A closed set. Every op composes its parameters out of these, which is why an op you have never seen still renders as a form you already know.

formulaNumber or expression, evaluated by the app. textPlayer-facing prose. selectorA target list — thing, tag or roll kind. enumOne of a fixed list. booleanOn or off. referenceA pick from the catalog, or from this feature’s own variables. arrayLevel-indexed progression: 21 slots, index 0 unused, levels 1–20.
06Audit
ErrorBlocks Save. Something the app cannot resolve. WarningInforms only. Save is allowed — an empty tag can be a tag nothing carries yet. CleanNothing outstanding.

Per-field help — each field’s schema description and example — lives behind Help in the editor header.
